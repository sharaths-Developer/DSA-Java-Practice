## 💻 How to Run Java Programs

Make sure Java JDK is installed.

Check Java version:

```bash
java --version
```

Compile a Java program:

```bash
javac Question01.java
```

Run the program:

```bash
java conditional_loops.Question01
```

*Run commands from the appropriate source directory and adjust the class name for the program you're executing.*
